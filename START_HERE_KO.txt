# Rouno Studio 1.10.0 Beta 시작 안내

할 일·일정·집중 시간과 자동화 작업의 결과를 한곳에서 확인하는 Windows 앱입니다. 현재 버전은 앞으로 독립 플러그인을 붙여 나갈 기본 버전입니다.

## 1.10.0에서 달라진 화면

- **Today**를 오늘의 영문 요일 바로 위에 파란 글씨로 표시합니다. 일요일·공휴일·토요일의 요일 색상은 유지합니다.
- 상단 공지 배너 안의 내용을 가운데 정렬합니다.
- 웹 브라우저를 열면 상단 바와 주변 배경을 흰색으로 통일하고 배경 그라데이션을 제거합니다. 다른 화면으로 돌아오면 기존 테마가 적용됩니다.
- 타이머 초기화 버튼을 상태 표시 옆의 우상단에 맞춥니다.
- Apple Silicon·Intel용 Mac Beta 설치 파일도 제공합니다. Mac은 새 버전 알림과 직접 설치·교체 방식이며, Windows 자동 업데이트는 유지합니다.

기존 할 일·일정·집중 기록, 단어·학습 기록과 플러그인 결과는 유지합니다. 저장 형식이나 연결·권한 범위는 바뀌지 않으며 새 계정 연결은 필요하지 않습니다.

## 설치

1. Windows 10/11의 64비트 PC에서 압축을 풀고 `RounoStudio-Setup-1.10.0.exe`를 실행합니다.
2. 설치 위치를 선택하고 설치를 마친 뒤 Rouno Studio를 실행합니다. Node.js, Git, GitHub 계정은 필요하지 않습니다.
3. 처음에는 빈 작업 공간이 열립니다. 할 일이나 일정을 추가해 보세요. 계정 연결 없이 기본 기능을 사용할 수 있습니다.

공식 배포 위치: https://github.com/JIwongeun/rouno-studio-releases/releases/latest

이 베타 설치 파일에는 코드 서명이 없어 Windows에서 게시자 확인 경고가 표시될 수 있습니다. 전달받은 파일의 출처와 아래 체크섬을 먼저 확인해 주세요. 회사·학교 PC에서 설치가 차단되면 관리자 정책을 따라 주세요.

## 먼저 사용해 보기

- Tasks에서 할 일을 적고 완료하거나 순서를 바꿉니다. 빈 목록의 버튼으로도 추가할 수 있습니다.
- 타이머 숫자 또는 게이지를 눌러 1–60분을 설정하고 시작합니다. Focus/Break 전환, 일시정지, 우상단 초기화가 가능합니다. 앱을 닫거나 PC가 절전 상태여도 시작한 타이머의 시간은 흐릅니다.
- 주간 날짜를 더블클릭하거나 Timeline의 +로 일정을 추가합니다. Month에서 한 달을 볼 수 있습니다.
- Shortcuts의 +로 사이트를 추가합니다. 수정은 편집 버튼, 우클릭 또는 F2를 사용합니다.
- 왼쪽 지구본으로 여러 브라우저 탭을 엽니다. Ctrl+T는 새 탭, Ctrl+W는 닫기, Ctrl+L은 주소 입력입니다.
- 지구본 아래 전원 플러그 모양 버튼에서 플러그인 파일을 가져와 소개, 사용 방법과 예시를 확인합니다. 설치된 플러그인은 기본 버튼 아래 구분선 밑에 개별 아이콘으로 나타납니다.
- Ctrl+K는 검색, Ctrl+N은 할 일 추가, Ctrl+Shift+N은 일정 추가, Ctrl+,는 설정입니다.

## 내 계정 연결

ChatGPT 등 웹사이트는 앱 브라우저에서 본인 계정으로 로그인합니다. 이 앱의 브라우저 저장소는 Chrome과 별개여서 북마크·확장 프로그램·Chrome 로그인은 자동으로 가져오지 않습니다. 사이트가 앱 내 로그인을 지원하지 않으면 외부 브라우저 열기를 이용하세요.

Codex는 선택 사항입니다. 본인 PC에 설치하고 로그인한 Codex가 있다면 설정 → 계정 연결 → Codex 연결을 누릅니다. 찾지 못하면 공식 `codex.exe`를 선택할 수 있습니다. 이 연결은 작업 기록과 사용량만 읽으며 작업을 실행하거나 계정을 변경하지 않습니다. 연결하지 않아도 할 일·일정·타이머·브라우저는 사용할 수 있습니다.

Google과 Jev도 설정 → 계정 연결에서 한 번 등록합니다. 플러그인에서는 이미 연결한 계정·키의 사용과 요청 권한만 승인합니다. Codex를 다시 로그인하거나 별도 작성 연결을 만들 필요가 없습니다. 배포자의 계정이나 키는 포함되지 않습니다.

## 영단어 루프 시작하기

플러그인 → **영단어 루프 → 설치 검토 → 승인하고 설치**를 선택하고 사용 설정을 켜세요. 기본 단어장과 시험에는 계정이나 API 연결이 필요하지 않습니다.

1. 왼쪽의 **영어 단어 입력** 칸 아래에 **품사 : 뜻**을 적습니다. 품사 표기는 입력란과 카드 모두 `n.`, `v.`, `a.`, `adv.` 같은 영어 약어를 씁니다. **+ 추가**로 뜻을 한 줄씩 늘릴 수 있고 같은 품사도 다시 선택할 수 있습니다. 오른쪽 위 **● / ●● / ●●●**로 중요도를 고르며 기본은 **1점**입니다.
2. 뜻 입력 후 **Enter**로 저장하면 다음 단어 입력란으로 이동하고 중요도는 다시 1점이 됩니다. **Shift+Enter**는 줄바꿈입니다. 항상 보이는 **메모**에는 예문이나 암기법을 자유롭게 적거나 비워 둡니다.
3. 여러 뜻은 쉼표, 같은 뜻의 다른 표현은 `/`로 구분합니다. 예: `유효한/효력이 있는, 타당한`. 저장한 단어는 오른쪽에 카드로 나란히 표시됩니다. 카드에는 메모가 항상 표시되고 **뜻 가리기**를 켜면 뜻과 메모가 함께 가려집니다. 영어 단어와 각 줄의 뜻을 입력해야 **단어 저장**이 활성화됩니다. 단어장에서 검색·정렬·수정할 수 있습니다.
4. 시험에서 **30개·50개·100개·전체**를 선택합니다. 등록된 단어가 적으면 있는 만큼 출제합니다. **뜻 쓰기**는 등록한 품사별로 답하고, **단어 고르기**는 다섯 카드에서 선택합니다. 객관식은 뜻이 겹치지 않는 다섯 보기를 만들 수 있어야 시작합니다.
5. 매 문제를 제출하면 바로 정답·오답과 원래 뜻·품사·중요도·메모가 보입니다. 복습한 뒤 다음 문제로 넘어가세요. 소리 아이콘으로 효과음을 끌 수 있습니다. 앱을 다시 열어도 시험을 이어 할 수 있습니다.

기본 채점은 품사마다 대표 뜻 하나를, ‘등록한 뜻 모두’는 모든 의미를 확인합니다. 다른 표현인데 의미가 맞으면 결과에서 **정답으로 수정**할 수 있습니다. 수정해도 응시 횟수는 늘어나지 않습니다. **Jev 의미 재검토**는 설정의 공유 연결을 사용하는 선택 기능이며, 전송을 확인한 문제의 단어·등록한 뜻·답안만 전송합니다. 메모와 다른 단어는 보내지 않으며 개인 API 사용량이 발생합니다. 불확실하거나 실패한 재검토는 기존 판정을 유지합니다.

복습 대상은 경과 시간·오답 이력·중요도·출제 빈도를 함께 반영합니다. 망각곡선에서 착안한 휴리스틱이며 개인별 기억 확률이나 최적 학습 효과를 검증한 모델은 아닙니다. 최대 단어 2,000개, 최근 시험 요약 40회와 상세 답안 2,000개를 보관합니다. 단어를 삭제해도 과거 답안의 뜻·메모 사본은 기록에 남고, 플러그인을 제거해도 단어장과 시험 기록은 보존합니다. 일반 JSON 백업에는 포함되지 않습니다.

## 중요 메일·관심 뉴스·논문 레이더 시작하기

왼쪽 플러그 버튼을 누르면 **중요 메일**, **관심 뉴스**, **논문 레이더**가 보입니다. 개요와 사용 방법을 읽고 ‘설치 검토’ → ‘연결과 권한’으로 진행하세요. 필요한 연결을 확인하고 권한에 동의해야 설치할 수 있습니다. 설치 직후에는 꺼져 있으며, 직접 켜야 수집과 분류를 시작합니다.

### 공통: Jev 연결

설정 → 계정 연결에서 개인 Jev API 키를 한 번 입력하고 ‘키 확인’을 누릅니다. 작은 연결 검증 요청 1회가 발생합니다. 활성화한 플러그인은 제목·내용·관심 기준을 Jev로 보내 분류하며 개인 API 사용량이 발생합니다. 키는 Windows 암호화 저장소로 보호되고 다시 표시하거나 내보내지 않습니다.

### 중요 메일

1. Google Cloud에서 Gmail API를 활성화합니다. OAuth 동의 화면을 설정하고 ‘데스크톱 앱’ 클라이언트를 만들어 JSON을 받습니다. 외부 테스트 앱은 자신의 Google 계정을 테스트 사용자에 등록해야 합니다.
2. 처음 연결한다면 설정 → 계정 연결에서 ‘OAuth JSON 가져오기’ 후 ‘Google 연결’을 누릅니다. 이미 연결되어 있다면 그대로 사용하며, 예전 메타데이터 권한만 있을 때 플러그인에서 ‘메일 읽기 권한 승인’만 누릅니다. 시스템 브라우저에서 본인의 계정으로 승인합니다. 보내기·삭제 권한은 요청하지 않습니다. Google 정책에 따라 토큰 만료 시 다시 연결해야 합니다.
3. 설정의 Codex 연결을 그대로 사용합니다. 이미 연결되어 있다면 플러그인 설치 시 사용만 승인하세요. 메일 작성은 ChatGPT 로그인 및 CLI **0.160.1**에서 지원됩니다. 이 버전에서 제한된 작성 프로토콜을 검증했으며 다른 CLI 버전은 지원 확인 전 차단됩니다. API 키 로그인은 대신 사용할 수 없습니다.
4. 설치·사용 설정 후 최근 7일 받은편지함 최대 30건을 확인합니다. 앱이 열려 있으면 15분마다 갱신합니다. 중요 메일을 아직 확인하지 않았다면 아이콘에 빨간 점이 표시됩니다.
5. 메일을 선택해 읽고 작성 도우미에 원하는 답장을 요청합니다. 선택 메일을 함께 전달할지 확인할 수 있습니다. **초안은 직접 검토해 복사하고 Gmail에서 보내세요.** 대화는 화면을 떠나면 사라집니다.

첨부파일은 읽지 않으며 긴 본문은 일부만 분류합니다. 불확실하거나 실패한 항목은 ‘확인 필요’에 남고 전체 목록도 볼 수 있습니다. 앱에서 확인해도 Gmail 자체 읽음 상태는 바뀌지 않습니다.

### 관심 뉴스

설정에 연결한 Codex 계정과 Jev 키를 사용합니다. 기존 설치에서는 플러그인 관리 → 관심 뉴스 → 업데이트 검토에서 Codex 사용 권한을 승인하고 사용 설정을 다시 켜 주세요. 이전 버전의 승인 상태를 유지하면 기존 검색식으로 수집을 계속할 수 있습니다.

뉴스 화면의 관심 기준 편집에서 어떤 일을 위해 무슨 소식을 보고 싶은지 문장으로 적고 **탐색 시작**을 누르세요. 키워드를 직접 고를 필요가 없습니다. Codex가 최대 5개 탐색 주제와 검색식을 만들고 Studio가 실제 공개 기사를 검색한 뒤 Jev가 목적과의 관련성을 판단합니다. 주제 버튼으로 결과를 좁혀 볼 수 있으며, 기준 편집의 펼침 항목에서 검색식을 확인할 수 있습니다.

목적을 적용할 때만 Codex를 호출합니다. 앱이 열려 있고 사용 중이면 저장한 검색식으로 30분마다 최근 7일 기사를 갱신합니다. Codex는 ChatGPT 로그인과 CLI 0.160.1에서 지원됩니다. Codex와 Jev 사용량이 발생하며 실패한 계획은 자동 재요청하지 않습니다. 기사 전문이 아닌 제목·출처·피드 설명을 분석합니다.

한 번에 최대 120건을 수집하고 최근 기사 최대 160건을 보관합니다. 기본 ‘전체’ 목록에서 확인할 수 있으며 ‘추천’으로 선별된 기사만 볼 수도 있습니다. 새 Jev 판단은 갱신당 최대 40건이고 나머지는 판단 대기 상태로 남습니다.

기사는 최신순입니다. 첫 소식은 사진과 큰 제목으로, 나머지는 일정한 너비의 읽기 목록으로 표시합니다. 사진이 없으면 텍스트만 표시하며 카드 높이를 억지로 늘리지 않습니다. 작은 불꽃은 수집된 기사 중 최근 24시간에 서로 다른 3개 이상 매체가 같은 제목을 보도한 경우이며 조회 수나 인터넷 전체 인기 순위가 아닙니다.

북마크로 최대 300개를 저장하고 저장됨에서 다시 볼 수 있습니다. 원문 전문을 오프라인으로 저장하지 않습니다. 더 보기에서 미리보기·관심 없음·출처 숨김을 사용할 수 있고, 숨김은 되돌리거나 관심 기준 편집에서 초기화할 수 있습니다. 새로 도착한 기사는 상단 알림을 눌러 목록에 반영합니다.

대표 이미지는 AI타임스·ZDNet Korea·Unite.AI에서 제목이 정확히 일치하는 공개 기사에 한해 표시됩니다. 사진을 못 찾는 기사는 텍스트로 남습니다. 이미지 접근을 아직 승인하지 않았다면 플러그인 관리에서 관심 뉴스의 업데이트 검토를 열어 추가 사이트 접근을 승인하고 사용을 다시 켜 주세요. 1.4.0 또는 1.4.1에서 승인한 이미지 권한은 유지됩니다. 목적 기반 탐색의 Codex 권한은 별도 업데이트 승인이 필요합니다. 기존 승인 상태를 유지해도 텍스트 뉴스와 저장된 결과는 사용할 수 있습니다. 사진 조회에는 별도 계정이나 Jev 사용량이 필요하지 않습니다.

### 논문 레이더

1.7.0부터 관심사 설정과 논문 읽기 화면을 새롭게 제공합니다. 기존 설치에서는 플러그인 관리 → 논문 레이더 → 업데이트 검토에서 새 출처와 번역 사용을 승인하고 사용 설정을 다시 켜 주세요.

1. 기존 Codex 계정과 Jev 연결을 확인하고 플러그인의 사용 권한을 승인합니다. 별도 논문 API 키는 필요하지 않습니다.
2. 처음에는 ‘나의 연구 관심사’에 궁금한 문제와 읽는 목적, 제외하고 싶은 내용을 자유롭게 적고 ‘관심사로 시작하기’를 누릅니다. 검색어를 직접 정할 필요는 없습니다.
3. 제안된 선별 기준과 학회를 확인합니다. 학회는 최대 5개까지 선택할 수 있고, ‘검색어와 학회 더 조정하기’에서 검색어·연도·다른 학회를 조정할 수 있습니다. ‘이 기준으로 시작하기’를 누르면 수집과 선별이 시작됩니다.
4. 이후에는 Jev가 통과시킨 논문이 바로 표시됩니다. 제목 아래에서 원문 초록과 한국어 번역을 읽고 ‘초록 전체 보기’로 펼치세요. ‘원문 열기’는 해당 논문의 출처를 엽니다. 원본에 초록이 없으면 그 사실을 표시합니다.
5. 한국어 초록은 연결된 Codex 계정으로 번역합니다. 한 번 확인할 때 최대 5편씩 자동 번역하며, 나머지는 다음 확인에서 이어집니다. ‘한국어로 번역’으로 직접 요청할 수도 있습니다. 실패한 번역은 자동 반복하지 않으며 ‘번역 다시 시도’를 눌러야 합니다.
6. 논문 오른쪽의 스크랩 아이콘을 누르면 ‘스크랩’ 탭에 보관됩니다. 최대 160편까지 저장하며, 관심 기준을 바꾸거나 앱을 다시 열어도 유지됩니다. 이후 설정 변경은 ‘관심 기준 편집’에서 진행하세요.

앱이 열려 있고 플러그인이 켜져 있을 때 6시간마다 확인합니다. Codex 제안·번역과 Jev 분류는 개인 계정 사용량을 사용합니다. 한국어 초록은 AI 번역이므로 중요한 표현은 원문과 함께 확인하세요. 이 버전의 Codex 실행은 CLI 0.160.1에서 지원됩니다.

ACL·EMNLP·NAACL·EACL·COLING은 공식 ACL Anthology의 최근 본 학회 논문을 사용합니다. 기존 사용자는 플러그인 관리의 ‘업데이트 검토’에서 새 출처 접근과 번역 사용을 승인하고 다시 켜야 합니다. 승인 전에는 기존 Crossref 수집과 저장된 논문 읽기를 유지합니다. Findings·워크숍은 현재 포함되지 않습니다. 다른 분야는 Crossref 학회 논문집을 사용하며, 새 연도에 논문집 이름이 바뀌면 다시 확인해야 할 수 있습니다. 학회 위상은 객관적 순위가 아니며, 미등재 학회와 학술지 중심 분야는 자료 범위가 제한됩니다.

### 해제와 외부 플러그인

사용 설정을 끄면 진행 중인 작업과 자동 확인이 중지됩니다. 메일·뉴스·논문 플러그인을 제거하면 해당 결과와 승인 기록을 지우지만 공유 계정·키·설정과 Gmail 원본은 남습니다. 영단어 루프는 제거 후에도 단어장·시험 기록을 보존합니다. 공유 연결을 지우려면 설정 → 계정 연결에서 직접 연결 해제하세요. Codex 연결 해제 시 진행 중인 작성도 중지됩니다. Gmail 계정을 해제하거나 변경하면 해당 메일 캐시를 비웁니다.

외부 설명 JSON 파일도 가져올 수 있습니다. 제작자 자유 형식 개요와 사용 예시를 지원하지만 외부 파일의 코드는 실행하지 않습니다. 지원하지 않는 필수 연결을 요구하면 설치가 차단됩니다. 로컬 파일의 제작자 표시는 검증된 신원이 아닙니다.

## 자동 업데이트

1. 인터넷이 연결돼 있으면 앱이 새 버전을 확인하고 자동으로 다운로드합니다. GitHub 가입·로그인·저장소 초대는 필요하지 않습니다.
2. 왼쪽 아래 업데이트 버튼에 로딩이 표시되다가 다운로드 아이콘으로 바뀝니다.
3. 준비된 버튼을 눌러야 저장 후 앱이 재시작되고 업데이트됩니다. 다운로드가 끝났거나 앱을 닫았다는 이유만으로 설치하지 않습니다.

설정 → 데이터 · 업데이트에서 직접 확인할 수도 있습니다. 네트워크 제한으로 업데이트가 안 되면 공식 배포 위치의 새 설치 파일을 받아 같은 위치에 설치합니다. 앱 데이터는 유지됩니다. Beta는 품질 단계 표시이며 버전 번호는 1.9.1입니다.

## 데이터와 백업

작업 자료는 이 PC의 `%APPDATA%\My Dash`에 저장됩니다. 별도 Rouno 서버나 동기화 기능은 없습니다. 웹사이트·Codex·날씨·업데이트 기능은 각각의 제공자에 연결됩니다.

설정 → 데이터 · 업데이트 → 백업 저장으로 할 일·일정·집중 기록·설정 등을 JSON으로 보관할 수 있습니다. 이 파일은 웹 로그인·API 인증 정보·플러그인 관리 기록·메일/뉴스/논문 결과·단어장을 포함하지 않습니다. 플러그인 기록은 plugins.json, 키와 메일·뉴스 결과는 Windows 암호화된 plugin-runtime.enc, 논문 계획·결과는 papers-runtime.enc, 단어장·시험 기록은 vocabulary-runtime.enc에 따로 저장됩니다. 현재 자동 백업 동기화나 백업 가져오기 화면은 없습니다. 앱을 제거해도 개인 데이터 폴더는 남습니다.

문제 신고에 데이터 폴더 전체, 브라우저 쿠키, Codex 인증 파일 또는 API 키를 첨부하지 마세요.

## 알려진 범위

- Windows x64 베타입니다. macOS/Linux, 모바일, 장치 간 동기화는 제공하지 않습니다.
- 자동 확인은 앱이 열려 있을 때만 동작합니다. 외부 실행형 플러그인 SDK는 다음 개발 범위입니다. 논문은 지원하는 학술 출처의 공개 메타데이터·초록을 수집하며, 논문 전체 본문을 읽거나 분석하지 않습니다.
- AI 선별은 틀릴 수 있습니다. 메일 원본도 확인해 주세요. Gmail 실계정 승인은 각 사용자가 완료해야 합니다.
- Codex 프로필 통계는 제공자 집계 시점에 따라 늦게 반영될 수 있습니다. 스킬 Total/최근 7일은 이 PC에 남아 있는 같은 기록을 기준으로 하며 원격·삭제된 기록은 빠집니다.
- 브라우저 탭 주소와 로그인 세션은 유지되지만 앱을 종료하기 전 페이지에 작성하던 미저장 입력은 복원되지 않습니다.
- 창의 최소 크기는 960×600이며, 작은 창이나 높은 화면 배율에서는 스크롤이나 잘림이 생길 수 있습니다. 주요 작업·설정·읽기 화면은 200% 확대를 포함한 지정 창 크기에서 검증했으며, 모든 화면·실제 장치 배율 조합에 대한 검증은 아닙니다. 공휴일 자료는 2018–2027년을 포함합니다.

## 파일 확인과 의견 보내기

동봉된 `SHA256SUMS.txt`와 파일 해시를 비교할 수 있습니다. PowerShell에서:

`Get-FileHash .\RounoStudio-Setup-1.10.0.exe -Algorithm SHA256`

배포자에게 앱 버전, Windows 버전/화면 배율, 어떤 순서로 조작했는지, 기대한 결과와 실제 결과를 알려 주세요. 필요하면 개인 정보가 보이지 않게 가린 화면을 함께 전달해 주세요. 오류 보고나 사용 기록을 자동으로 전송하는 기능은 없습니다.
