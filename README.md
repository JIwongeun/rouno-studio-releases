# Rouno Studio · Beta

할 일·일정·집중 시간과 자동화 업무의 결과를 한곳에서 확인하는 Windows·Mac 작업 스튜디오입니다.

**[최신 설치 파일과 사용 안내 받기](https://github.com/JIwongeun/rouno-studio-releases/releases/latest)**

- Windows x64, macOS 13 이상 Apple Silicon·Intel용입니다. GitHub 계정, Git, Node.js 없이 설치할 수 있습니다.
- Windows는 `RounoStudio-Setup-버전.exe`를 받습니다. `RounoStudio-버전-Beta.zip`에는 Windows 설치 파일, 한국어 시작 안내와 체크섬이 들어 있습니다. [Windows 안내](START_HERE_KO.txt)
- Mac의 Apple M 시리즈 칩은 `RounoStudio-버전-mac-arm64.dmg`, Intel 프로세서는 `RounoStudio-버전-mac-x64.dmg`를 받습니다. [Mac 설치·교체 안내](START_HERE_MAC_KO.txt)
- Windows는 새 버전을 자동 다운로드하며, 준비된 업데이트 버튼을 눌러야 저장 후 설치·재시작합니다. Mac Beta는 새 버전을 알리고 다운로드 페이지를 엽니다. 앱을 종료한 뒤 새 DMG로 직접 교체합니다.
- 개인 자료는 각자의 PC에 저장됩니다. 웹 계정은 본인이 로그인하고, Codex 읽기 전용 연결은 선택 사항입니다.
- 중요 메일·관심 뉴스·논문 레이더를 필요한 만큼 설치합니다. 설정에서 자신의 계정·Jev API를 연결하고 플러그인별 사용 권한을 승인한 뒤 켜세요. 외부 실행형 플러그인 SDK는 아직 제공하지 않습니다.
- 논문 레이더는 관심사를 설명하면 학회와 선별 기준을 제안하고, 확인한 최대 5개 학회에서 Jev가 통과시킨 논문을 모읍니다. ACL Anthology·Crossref의 원문 초록과 출처, Codex 한국어 번역과 스크랩을 제공합니다. 기존 사용자는 플러그인 업데이트에서 새 출처와 번역 사용을 승인하세요. 앱이 열려 있고 사용 설정이 켜져 있으면 6시간마다 확인하며, 제공자의 자료 범위·초록 누락·출판 지연에 따라 결과가 달라집니다.
- 영단어 루프에서 단어·품사별 뜻·중요도·메모를 모으고 뜻 쓰기·다섯 보기 시험으로 복습합니다. 중요도는 기본 1점이고 Enter로 연속 추가할 수 있습니다. 기본 단어장·시험은 계정 없이 작동하며, Jev 의미 재검토는 선택 기능입니다. 단어장은 일반 JSON 백업에 포함되지 않습니다.

이 저장소는 **설치 파일·업데이트 정보·사용자 안내만** 배포합니다. 애플리케이션 소스와 개인 데이터는 포함하지 않습니다. 별도 Rouno 계정이나 서버 설정은 없습니다.

Windows 설치 파일은 미서명이며, Mac은 Apple Developer ID 서명과 공증을 받지 않은 Beta입니다. Mac 최초 실행 시 시스템 설정에서 확인 절차가 필요할 수 있습니다. 배포 출처와 동봉된 SHA256SUMS.txt를 확인해 주세요. 실제 MacBook의 최초 설치 승인·계정 로그인·이전 설치본 교체는 아직 검증하지 않았습니다. 오류를 전달할 때에는 버전·재현 순서와 개인 정보를 가린 화면만 공유하고, 인증 파일·쿠키·API 키를 올리지 마세요.
