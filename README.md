# Rouno Studio · Beta

할 일·일정·집중 시간과 자동화 업무의 결과를 한곳에서 확인하는 Windows 작업 스튜디오입니다.

**[최신 설치 파일과 사용 안내 받기](https://github.com/JIwongeun/rouno-studio-releases/releases/latest)**

- Windows x64용입니다. GitHub 계정, Git, Node.js 없이 설치하고 자동 업데이트할 수 있습니다.
- RounoStudio-버전-Beta.zip에는 설치 파일, 한국어 시작 안내와 체크섬이 들어 있습니다.
- 새 버전은 자동 다운로드되며, 준비된 업데이트 버튼을 눌러야 저장 후 설치·재시작합니다.
- 개인 자료는 각자의 PC에 저장됩니다. 웹 계정은 본인이 로그인하고, Codex 읽기 전용 연결은 선택 사항입니다.
- 중요 메일·관심 뉴스·논문 레이더를 필요한 만큼 설치합니다. 설정에서 자신의 계정·Jev API를 연결하고 플러그인별 사용 권한을 승인한 뒤 켜세요. 외부 실행형 플러그인 SDK는 아직 제공하지 않습니다.
- 논문 레이더는 관심사를 설명하면 학회와 선별 기준을 제안하고, 확인한 최대 5개 학회에서 Jev가 통과시킨 논문을 모읍니다. ACL Anthology·Crossref의 원문 초록과 출처, Codex 한국어 번역과 스크랩을 제공합니다. 기존 사용자는 플러그인 업데이트에서 새 출처와 번역 사용을 승인하세요. 앱이 열려 있고 사용 설정이 켜져 있으면 6시간마다 확인하며, 제공자의 자료 범위·초록 누락·출판 지연에 따라 결과가 달라집니다.
- **토익 도우미**는 연결한 GPT로 초급·중급·상급 각 1문제씩 오늘의 Part 5·6·7 문제를 만듭니다. 네 보기에서 답을 고르면 필요한 지식, 빠르게 푸는 순서, 오답 함정, 해석과 근거를 확인할 수 있습니다. 오늘 문제는 한국 시간 자정에 지워지고 직접 스크랩한 해설은 계속 보관합니다. 기존 설치는 플러그인 업데이트에서 GPT 사용을 승인하세요. AI 연습 문제로 오류가 있을 수 있으며 생성·검토에 여러 분과 연결한 계정의 사용량이 필요합니다. 기존 단어장·메모·단어 시험과 다국어 입력을 유지하고 오프라인으로 사용할 수 있습니다. 단어장과 스크랩은 일반 JSON 백업에 포함되지 않습니다.

1.17.1에서는 **대학원 면접의 연구실 분석을 Codex 웹 조사로 바꿨습니다.** 대학원 이름과 URL을 보내면 Codex가 연구실·교수 소개와 관련 논문을 찾아 정리합니다. 앱의 별도 본문 수집기와 같은 사이트 6페이지 제한을 제거했습니다. 읽을 수 없는 페이지는 관련 공개 자료를 더 조사하고 확인하지 못한 범위를 표시합니다. 기존 첨부 자료·질문·답변·평가 기록과 사용 승인을 유지합니다. 업데이트 후 **연구실 분석하기** 또는 **연구실 다시 분석**을 누르세요.

1.17.0에서는 **대학원 면접** 플러그인을 추가했습니다. 지원 대학원·연구실 웹사이트와 제출한 CV·자소서·성적증명서를 연결해 연구 적합성, 준비할 내용과 예상 질문을 만듭니다. 텍스트 답변에 항목별 점수·피드백·꼬리질문을 제공하고 대학원별 기록을 보존합니다. **플러그인 → 대학원 면접 → 설치 검토**에서 시작하세요. AI 작업은 직접 요청할 때 설정의 ChatGPT 기반 Codex 연결(CLI 0.160.1)과 계정 사용량을 사용합니다. 마이크·녹음은 없으며 점수는 합격 확률이 아닙니다. PDF·DOCX·TXT·MD를 지원하며 스캔 문서는 텍스트로 변환해 첨부하세요.

1.16.0에서는 **메모 테두리·모서리를 드래그해 가로·세로 크기를 조절하고 저장할 수 있습니다.** 확대·축소 상태에서도 동작하며 조절점의 방향키·Shift+방향키를 지원합니다. 드래그 중 Esc로 취소할 수 있고, 연결선·검색 이동·전체 보기에도 크기를 반영합니다. 기본 320×240, 최소 240×160, 최대 2400×2400입니다. 기존 본문·위치·중요 표시·시각과 사용 승인을 유지합니다. 변환된 메모 저장소는 1.15.1 이하에서 읽을 수 없으므로 업데이트 후 이전 버전으로 되돌리지 마세요.

1.15.1에서는 **메모 게시판의 제목 입력란을 없애고 본문에 바로 적도록 바꿨습니다.** 본문 공간을 넓히고 이력·검색·자동 연결도 내용 기준으로 정리했습니다. 기존 제목은 본문 위에 빈 줄을 두고 한 번만 합쳐 보존하며 메모 위치·게시판·중요 표시·시각과 사용 승인을 유지합니다. 자동 저장과 실패 후 재시도도 그대로 사용할 수 있습니다. 변환된 메모 저장소는 1.15.0에서 읽을 수 없으므로 업데이트 후 이전 버전으로 되돌리지 마세요.

1.15.0에서는 **독립 플러그인 메모 게시판**을 추가했습니다. 주제별 게시판에 메모를 자유롭게 배치하고, 같은 단어를 포함한 메모를 자동 연결합니다. 빈 배경 드래그로 이동하고 Ctrl+클릭으로 메모를 만듭니다. 최근 수정순 목록에서 현재/전체 게시판을 검색할 수 있습니다. 설치 승인 후 사용을 켜면 기존 학습노트를 LC/RC/미분류 게시판으로 옮기고 내용·중요 표시·시각을 보존합니다. 저장 검증이 끝난 뒤 기존 탭을 숨기며 실패 시 기존 내용을 읽을 수 있습니다. 메모는 계정·API 연결 없이 이 PC에 암호화 저장됩니다. 자동 연결은 단어 일치에 한정됩니다. 이전 후 구버전 앱으로 기존 노트를 편집하지 마세요.

1.14.0에서는 **단어 시험을 하나로 통합하고 단어별 기록에 따라 네 유형을 독립 추첨합니다.** 단어→뜻 5지선다, 뜻→단어 5지선다, 뜻 직접 입력, 뜻을 보고 첫 글자 뒤에 나머지 철자 입력을 지원합니다. 자주 틀리는 단어는 더 자주 나오며 선택형 확률이 높고, 선택형에서도 정답이 쌓이면 출제 가중치는 낮아지고 입력형 확률이 올라갑니다. 유형별 개수는 고정하지 않습니다. 30·50·100개는 가중 추첨, 전체는 모든 단어를 한 번씩 내면서 순서에 가중치를 반영합니다. 기존 기록과 시험 중 단어 수정은 유지되며 새 유형을 저장한 프로필은 1.14.0 이상으로 사용하세요.

1.13.4에서는 **단어 시험에서 답을 확인한 뒤 우측 해설의 단어를 바로 수정할 수 있습니다.** `단어 수정`에서 단어·품사·뜻·메모·중요도를 고치고 `변경 저장`으로 단어장에 반영한 뒤 시험을 이어가세요. 제출한 답의 채점은 유지되며 기존 버튼으로 별도 조정할 수 있습니다.

1.13.3부터 **단어 시험에서 채점 후 Enter로 다음 문제로 넘어갈 수 있습니다.** 주관식·객관식 모두 지원하며 마지막 문제에서는 결과 화면을 엽니다. 한글 조합·키 길게 누르기·확인창에서 실수로 넘어가지 않도록 보호하고 다른 버튼의 키보드 동작을 유지합니다. 기존 단어·메모·시험 기록·학습 노트·플러그인 순서와 권한은 유지됩니다.

1.13.2부터 **단어장 수정 버튼을 눌러도 현재 스크롤 위치를 유지합니다.** 좁은 창·확대 화면에서 여러 줄의 뜻을 편집할 때도 불필요한 이동을 막았으며, 변경 저장·수정 취소와 마우스·키보드 조작을 확인했습니다.

1.13.1부터 왼쪽 플러그인 아이콘을 약 0.45초 꾹 누르면 **반투명 아이콘이 마우스를 따라옵니다.** 원하는 위치의 **파란 삽입선에 놓으면** 그 자리로 이동하고 자동 저장됩니다. Esc 또는 패널 밖에 놓기로 취소할 수 있고, 키보드는 Alt+↑/↓를 사용합니다. 재실행하거나 플러그인을 업데이트해도 순서를 유지합니다.

1.12.0에서 도입한 학습 노트는 1.15.0에서 메모 게시판으로 이전됩니다. 이전 버전의 **학습 노트**에는 자동 저장·LC/RC 분류·검색·중요 표시·가리고 복습하기를 추가합니다. 단어 시험은 왼쪽 문제·오른쪽 해설의 고정 크기 패널로 구성하고, 정답 여부와 관계없이 다섯 보기의 영단어 오른쪽에 품사와 모든 뜻을 표시합니다. 품사 간격과 불필요한 파란 포커스 사각형도 개선했습니다. 기존 단어·시험·오늘의 문제·스크랩과 권한을 유지합니다. 노트는 이 PC에 보관되며 자정에도 삭제되지 않고 일반 JSON 내보내기·클라우드 동기화에는 포함되지 않습니다. 확장된 토익 저장 형식은 1.12.0 이상에서 사용하세요.

이 저장소는 **설치 파일·업데이트 정보·사용자 안내만** 배포합니다. 애플리케이션 소스와 개인 데이터는 포함하지 않습니다. 별도 Rouno 계정이나 서버 설정은 없습니다.

설치 파일은 아직 코드 서명되지 않았습니다. 배포 출처와 동봉된 SHA256SUMS.txt를 확인해 주세요. 오류를 전달할 때에는 버전·재현 순서와 개인 정보를 가린 화면만 공유하고, 인증 파일·쿠키·API 키를 올리지 마세요.
