# Rouno Studio 1.10.0 Beta — Mac 설치 안내

이번 Mac Beta는 **새 버전 알림 + 직접 설치·교체** 방식입니다. Apple Developer ID 서명과 공증을 받지 않았으며, 처음 실행할 때 macOS의 확인 절차가 나타날 수 있습니다. Windows 버전의 자동 다운로드·재시작 설치와 방식이 다릅니다.

## 내 Mac에 맞는 파일

macOS 13 이상용입니다.

Apple 메뉴 → 이 Mac에 관하여에서 칩/프로세서를 확인하세요.

- Apple M 시리즈 칩: `RounoStudio-1.10.0-mac-arm64.dmg`
- Intel 프로세서: `RounoStudio-1.10.0-mac-x64.dmg`

[공식 배포 페이지](https://github.com/JIwongeun/rouno-studio-releases/releases/latest)에서 받습니다. GitHub 계정은 필요 없습니다. Windows용 EXE나 소스 코드 ZIP은 Mac 설치 파일이 아닙니다.

## 처음 설치하기

1. 해당 DMG를 열고 `Rouno Studio.app`을 응용 프로그램 폴더로 옮깁니다.
2. DMG를 꺼낸 뒤 응용 프로그램 폴더의 앱을 실행합니다.
3. 개발자 또는 Apple 확인을 받지 않았다는 이유로 실행이 차단되면, 다운로드한 출처를 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 사용합니다. macOS 버전에 따라 문구와 위치가 조금 다를 수 있습니다.

이 절차는 Apple이 앱의 안전성을 검증했다는 뜻이 아닙니다. 악성 소프트웨어 경고나 손상된 앱 경고가 나오면 실행을 중단하고 배포자에게 알려 주세요. 보안 기능을 전체 해제하는 명령은 필요하지 않습니다. 자세한 절차는 [Apple 안내](https://support.apple.com/en-us/102445)를 확인하세요.

## 새 버전으로 바꾸기

앱이 시작하거나 일정 시간이 지나면 새 버전을 확인합니다. 새 Mac 파일이 준비되면 사이드바와 설정 → 데이터 · 업데이트에 다운로드 버튼이 나타납니다.

1. 다운로드 버튼으로 배포 페이지를 엽니다. 앱이 자동 종료되거나 교체되지는 않습니다.
2. 자신의 칩에 맞는 최신 DMG를 받습니다.
3. 작업을 저장한 뒤 Rouno Studio를 완전히 종료합니다.
4. 새 DMG의 앱을 응용 프로그램 폴더로 옮기고 기존 앱을 대치합니다.
5. 응용 프로그램 폴더에서 다시 실행하고 설정의 버전을 확인합니다. 새 버전에서 실행 확인을 다시 요구할 수 있습니다.

기존 앱 데이터 폴더를 지우지 않으면 일정·할 일·학습 기록은 유지됩니다. 앱이 실행 중인 상태에서 교체하지 마세요. Windows와 Mac 사이에 자동 동기화되지는 않습니다.

## 저장 위치와 계정

개인 데이터는 `~/Library/Application Support/My Dash`에 저장합니다. 설정 → 데이터 · 업데이트 → 폴더 열기로 확인할 수 있습니다. 설정의 백업은 일정 등 기본 작업 데이터이며, 연결 계정·암호화된 플러그인 데이터·브라우저 로그인까지 모두 옮기는 전체 백업은 아닙니다. Mac Keychain으로 암호화된 파일은 다른 컴퓨터에 그대로 옮겨 사용할 수 없습니다.

기본 일정·할 일·타이머는 계정 없이 사용할 수 있습니다. Google, Codex, Jev 연결은 각자 설정하며 플러그인은 별도 승인이 필요합니다. 앱을 교체한 뒤 Keychain 접근을 다시 확인할 수 있습니다. 기존 연결을 읽지 못하면 설정에서 다시 연결하세요. Codex CLI를 자동으로 찾지 못하면 설정 → 계정 연결 → CLI 선택에서 공식 `codex` 실행 파일을 선택합니다. 터미널에서는 동작하지만 앱에서 찾지 못한다면 사용자 정의 Node 경로 대신 실제 실행 가능한 네이티브 Codex 바이너리를 선택해 주세요.

주요 단축키는 Mac에서 Command 키를 사용합니다. Command+K는 검색이며, 브라우저에서는 Command+T로 새 탭, Command+W로 탭 닫기, Command+L로 주소 입력을 사용할 수 있습니다. 이번 Beta는 창을 닫으면 저장 후 앱을 종료합니다.

## 테스트 범위

Mac 배포는 Apple Silicon·Intel용 자동 빌드와 격리된 앱 테스트를 사용합니다. 개발자에게 직접 확인할 Mac은 없습니다. 실제 MacBook에서의 최초 설치 승인, 실제 계정 로그인, 재부팅 후 로그인 자동 실행 및 이전 설치본 교체는 테스터의 확인이 필요합니다. 문제를 알려 줄 때는 Mac 칩, macOS 버전, 앱 버전, 재현 순서와 오류 문구를 함께 전달해 주세요. 비밀번호·API 키·개인 데이터 폴더는 보내지 마세요.
